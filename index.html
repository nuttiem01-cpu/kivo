About Kivo.

Kivo is a small, standalone study tool for vocabulary, concepts and other paired learning material. Choose or create a list, recall each answer, and repeat the entries that need more practice.

  • Import and export portable CSV lists.
  • Practice either direction, in full or progressive mode, with optional hints.
  • Review mistakes and keep per-list progress in this browser.

Open index.html directly to use Kivo offline. Lists and progress stay in this browser; use CSV or a workspace backup to move a copy. There is no account or cloud sync.

The optional book link opens Google Translate and sends the answer when clicked.
